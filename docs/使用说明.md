# pjournal-esp32 使用说明

适用版本：v4.9.9

本机是一台 ESP32-S3 的掌上写作设备：4.2 寸黑白反射屏、蓝牙键盘输入、中文拼音输入法，
内置日记、GTD、大纲、灵感、Flomo 笔记与 WebDAV 同步。本文是完整使用手册；设备上也可以通过
主界面的 **[?] 使用说明** 阅读精简版（分章节，支持翻页）。

## 1. 开箱与首次设置

### 1.1 硬件

| 组件 | 说明 |
|------|------|
| 主控 | ESP32-S3，8MB PSRAM，16MB Flash |
| 屏幕 | 4.2 寸 RLCD 反射屏，400×300，黑白 |
| 键盘 | 蓝牙 HID 键盘（BLE） |
| 存储 | microSD 卡，FAT32 |
| 时钟 | PCF85063 RTC，纽扣电池供电 |
| 电池 | 单节 3.7V 锂电池，屏幕状态栏显示电量 |
| 按键 | BOOT（GPIO0）、USER（GPIO18） |

屏幕是反射屏：环境光越亮越清楚，不需要背光，也没有背光。

### 1.2 首次开机

1. **准备 SD 卡**：格式化为 FAT32，插入设备。
2. **连接键盘**：长按 **USER** 键进入「蓝牙管理」，上下键选择键盘，长按连接。
   已配对的键盘在之后开机或唤醒时会自动重连。
3. **配置网络**：主界面按 `s` 进入设置 → 展开「连接管理」，填写 WiFi SSID/密码、
   时区（如 `CST-8`）、NTP 服务器。
4. **同步时间**：在「连接管理」里执行「网络同步时间」，联网后自动校准 RTC。
5. **（可选）配置账号**：同一设置页的「账号相关」里填写 DeepSeek Key、Flomo 邮箱/密码、
   WebDAV 地址等。

设备上的功能入口和按键提示都写在屏幕上，不确定时按 `?` 打开使用说明。

## 2. 主界面

主界面从上到下分为：

- 日期与本周记录（周视图或月视图，可在设置中切换）；
- 一行功能图标；
- 当前选中功能的名称与快捷键；
- 底部状态栏：日期、电量、蓝牙键盘电量。

### 2.1 操作

| 按键 | 功能 |
|------|------|
| `←` `→` / `h` `l` / `↑` `↓` | 在功能图标间移动 |
| `Enter` | 进入当前选中功能 |
| 字母键 | 直接进入对应功能 |

图标放不下时整行横向滚动，左右两侧出现 `<` `>` 提示。

### 2.2 功能入口

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `p` | 提示写作 | 随机给出一句写作提示 |
| `f` | 自由写作 | 新建空白日记 |
| `v` | 查看过往日记 | 浏览、编辑、删除、历史版本 |
| `w` | 同步 WebDAV | 与远端存储同步日记 |
| `t` | GTD 任务管理 | 分层任务、项目、标签 |
| `o` | 大纲写作 | 大纲式文档与摘要 |
| `n` | Flomo 笔记 | 本地笔记库 + 手动同步 |
| `s` | 设置 | 全部系统设置 |
| `?` | 使用说明 | 设备内置的本手册精简版 |

`Ctrl+I` 在任意界面都能打开灵感面板。

## 3. 写日记

### 3.1 自由写作（`f`）

新建一篇空白日记，直接输入正文。文件名自动按 `YYYY-MM-DD_HHMMSS.txt` 生成。

### 3.2 提示写作（`p`）

从内置提示库里随机取一句写作提示，围绕它记录。提示不会写进正文，只是开头的引子。

### 3.3 输入

- 连接蓝牙键盘后直接打字。
- 中文输入：`Ctrl+Space` 切换中/英，输入拼音后数字键选字，空格选第一个，
  `←` `→` 翻页，`Esc` 取消本次输入。
- 更多输入法功能见[第 13 节](#13-输入法)。

### 3.4 保存与退出

| 操作 | 行为 |
|------|------|
| `Ctrl+S` | 立即保存 |
| `Esc` | 退出；若有未保存改动，弹出确认框：`Enter`/`y` 保存并退出，`Esc`/`n` 放弃 |
| `Ctrl+Q` | 直接退出编辑 |
| 自动保存（设置开启） | 停笔 3 秒自动保存 |
| 恢复草稿（设置开启） | 断电/崩溃后，下次进入可恢复未保存内容 |

## 4. 编辑器

编辑器支持 Markdown 实时渲染、标题折叠、选择/复制/粘贴、查找替换、撤销重做、
历史版本、AI 提示、AI 润色、语音听写和发送到 Flomo。

### 4.1 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+S` | 保存 |
| `Ctrl+Q` | 退出编辑 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+R` / `Ctrl+Shift+Z` | 重做 |
| `Ctrl+Y` | 查看当前日记的历史版本 |
| `Ctrl+P` | AI 生成写作提示（个人日记模式） |
| `Ctrl+F` | 发送正文到 Flomo |
| `Ctrl+O` | AI 润色选中文本 |
| `Ctrl+T` | 折叠/展开光标所在标题下的正文 |
| `Ctrl+/` | 打开查找/替换 |
| `Ctrl+?` | 编辑器快捷键帮助 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 复制 / 剪切 / 粘贴 |
| `Ctrl+A` | 全选 |
| `Shift+方向键` | 选择文本 |
| `Home` / `End` | 行首 / 行尾 |
| `PageUp` / `PageDown` | 上一屏 / 下一屏 |
| 双击 `BOOT` | AI 全文润色 |
| 双击 `USER` | 语音听写 |

### 4.2 查找/替换（`Ctrl+/`）

| 按键 | 功能 |
|------|------|
| `Enter` | 下一处匹配 |
| `Ctrl+Enter` | 上一处匹配 |
| `Tab` | 切换查找/替换输入框 |
| `Ctrl+R` | 替换当前匹配 |
| `Ctrl+A` | 全部替换 |
| `Esc` | 关闭 |

### 4.3 版本历史

开启「版本历史」后，每次保存会自动生成快照，每篇日记保留最近 10 个版本。
在编辑器里按 `Ctrl+Y`，或在日记列表/详情里按 `h` 进入：

| 按键 | 功能 |
|------|------|
| `j` / `k` | 选择版本 |
| `Enter` | 预览 |
| `r` | 恢复所选版本（`Enter` 确认） |
| `d` | 删除所选版本（`Enter` 确认） |
| `q` / `Esc` | 返回 |

### 4.4 打字机模式与打字音效

设置 →「模式设置」里可切换「输入模式」为正常或打字机：

- 打字机模式：光标始终保持在屏幕中间，不足时顶部留白；
- 打字音效：18 种机械/静电容轴体采样，可选音量、音色，以及按键触发或上屏触发。

### 4.5 竖排、行号与 Vi 模式

- 「文字方向」可切换横排/竖排；竖排可显示参考线（实线/虚线/点状虚线）。
- 「显示行号」在正文左侧显示行号。
- 「Vi 模式」开启后，编辑器使用 vi 风格的模式化操作（插入/普通/可视）。

## 5. Markdown 与排版

### 5.1 块级标记

| 输入 | 渲染效果 |
|------|----------|
| `#` ~ `######` 标题 | 标题符号 + 内容加粗、下划线 |
| `- ` / `* ` / `+ ` 无序列表 | `•` 圆点 |
| `1. ` / `1)` / `1、` 有序列表 | 序号加粗，整体右移 |
| `一、` / `二、` 中文序号 | 序号加粗，整体右移 |
| `- [ ]` / `- [x]` 任务 | `☐` / `✓` |
| `> ` 引用 | 左侧竖线 + 内容缩进 |
| `---` / `***` / `___` | 水平分割线 |
| ```` ``` ```` 代码围栏 | 围栏行画横线，围栏内反白 |

列表行回车自动续行：无序列表带同款标记，有序列表序号自动加一；空列表项回车结束列表。

### 5.2 行内标记

| 输入 | 渲染效果 |
|------|----------|
| `**加粗**` | 加粗 |
| `***加粗+下划线***` | 加粗 + 下划线 |
| `*斜体*` | 下划线 |
| `` `代码` `` | 反白 |
| `[链接](https://…)` | 反白 + 下划线 |
| `~~删除~~` | 删除线 |
| `==高亮==` | 着重号 |
| `\*` | 转义，显示原文 |

### 5.3 标题折叠

光标停在标题行，按 `Ctrl+T` 折叠该标题下的正文，再按一次展开。折叠后标题图标保留并追加
折叠标志；支持嵌套折叠，光标进入折叠区时会自动展开。

### 5.4 其他排版设置

- **首行缩进**：普通段落首行缩进两个中文字符。
- **Markdown渲染**：可整体关闭，关闭后显示原始标记。
- **字体大小**：影响候选字与正文显示字号。

## 10. Flomo 笔记

主界面按 `n` 打开。这是一个**本地优先**的 Flomo 客户端：笔记先写进 SD 卡上的本地库，
按 `S` 手动同步时才与 flomoapp.com 交换数据。适合在没有网络时先记录、联网后再同步。

### 10.1 列表快捷键（区分大小写）

| 按键 | 功能 |
|------|------|
| `N` | 新建笔记（借用写作编辑器） |
| `Enter` | 查看详情 |
| `E` | 编辑当前笔记 |
| `C` | 复制正文到粘贴板 |
| `D` | 删除当前笔记（`Enter` 确认） |
| `S` | 手动同步：先推本地改动，再增量拉远端 |
| `T` | 标签树 / 按标签筛选 |
| `/` | 搜索正文 |
| `?` | Flomo 页帮助 |
| `Esc` / `q` | 返回主界面 |

`j`/`k`、`↑`/`↓`、`PageUp`/`PageDown`、`Home`/`End` 用于列表和详情滚动。

### 10.2 本地改动与同步

- 新建、编辑、删除都只修改本地库，**不会立即上传**。
- 列表里带 `*` 的条目表示有未同步的本地改动。
- 按 `S` 开始同步，顺序是：
  1. 连接 WiFi（若未连接）；
  2. 逐条上传本地改动（新建 / 修改 / 删除）；
  3. 按上次同步游标增量拉取远端更新；
  4. 原子写回本地库。
- 同步进度与结果直接显示在屏幕上。若写盘失败，会提示「写盘失败(SD内存不足)」，
  本次同步按失败处理，不会假装成功。
- 令牌过期（业务码 -10/-20）时，会自动用设置里保存的 Flomo 邮箱/密码重新登录一次，
  再重试当前请求。

### 10.3 标签

- 正文里的 `#标签` 会被 Flomo 识别为标签，支持 `父/子` 形式的层级路径。
- 按 `T` 打开标签树：树按层级缩进显示，右侧是笔记数量。
- `Enter` 按选中标签筛选；选第一行「全部」清除筛选。
- 列表标题会显示当前筛选的标签。
- 标签树里的父标签会匹配它下面所有子标签。

### 10.4 搜索

按 `/` 输入关键词，按正文内容过滤；`Enter` 应用，`Esc` 返回。搜索和标签筛选可以叠加使用。

### 10.5 账号与本地库

- 设置 →「账号相关」里填写 **Flomo 邮箱 / 密码**；「生成 Flomo Token」可以手动换取 Token。
- Token 保存在本地库的 `token` 字段里，与「发送到 Flomo」功能共用同一份配置。
- 本地库位置：`/sdcard/flomo/memos.json`，采用原子写，避免断电写坏。
- 删除在远端是软删除；本地列表里删除后，下次同步会把删除操作推上去。

## 11. WebDAV 同步

1. 在设置 →「账号相关」里填写 WebDAV URL、用户名、密码；
2. 在「连接管理」里配置 WiFi；
3. 主界面按 `w` 开始同步，设备自动联网并上传/下载日记；
4. 屏幕上显示同步进度，完成后短暂显示结果并返回。

同步耗时取决于网络和日记数量，通常几秒到几十秒。失败时请检查网络、地址和账号，然后重试。

## 12. 语音、AI 润色与 AI 提示

### 12.1 语音听写

在编辑器中双击 `USER` 键开始实时语音听写，识别结果直接进入正文。需要：
- 设置 →「账号相关」→「语音识别服务」选择服务；
- 按所选服务填写百度 Api Key / Secret Key 等凭证；
- 已连接 WiFi。

### 12.2 AI 润色

- 编辑器里选中文本，按 `Ctrl+O` 润色选中部分；
- 双击 `BOOT` 润色全文；
- 润色规则可在设置 →「账号相关」→「润色提示词」里自定义（多行文本，替换内置默认规则）。

需要 DeepSeek Key 并联网。

### 12.3 AI 写作提示

编辑器里按 `Ctrl+P`，根据设置里的「个人经历」「个人爱好」生成写作提示。
需要 DeepSeek Key 并联网。

## 13. 输入法

### 13.1 基本切换

| 按键 | 功能 |
|------|------|
| `Ctrl+Space` | 中 / 英输入法切换 |
| `Shift+Space` | 全角 / 半角切换 |
| `Ctrl+Shift+F` | 繁体 / 简体切换 |
| `Ctrl+D` | 删除动态用户词（输入编码后选择要删除的词） |
| 左 `Shift` 单击 | 临时英文模式 |
| `1`-`9` | 选择候选字 |
| `Space` | 选择第一个候选 |
| `←` / `→` | 候选翻页 |
| `Esc` | 取消本次输入 |

拼音支持模糊音、联想候选、整句候选、正文词优先等选项，均在设置 →「输入法设置」中。

### 13.2 v 模式快捷输入

输入裸 `v` 会弹出常用颜文字候选。`v/编码` 可按拼音或声母搜索颜文字，例如
`v/kaixin`、`v/kx` 匹配「开心」相关表情，支持渐进过滤；闭合 `v/kaixin/` 或输入完整编码后
数字键 1-9 直选。

| 输入 | 内容 |
|------|------|
| `v/bd` | 中文标点 |
| `v/t/` | 时间（3 种格式） |
| `v/d/` | 日期（3 种格式） |
| `v/w/` | 星期（英文/中文） |

方向键移动反白高亮，空格或回车确认。

### 13.3 英文输入

英文模式下输入字母会出现单词联想（内置万词词库）；首字母大写时候选自动大写。
连续上屏两个单词且中间无空格时，自动补空格分隔。

### 13.4 词库管理

设置 →「输入法设置」→「词库管理」，可查看、搜索、多选删除、添加词条：

| 词库 | 导入文件 | 导出文件 |
|------|----------|----------|
| 动态词库 | `/sdcard/settings/userdict_import.txt` | `/sdcard/settings/userdict_export.txt` |
| 固定词库 | `/sdcard/settings/userdict_fixed_import.txt` | `/sdcard/settings/userdict_fixed_export.txt` |
| 联想词库 | `/sdcard/settings/userpredict_import.txt` | `/sdcard/settings/userpredict_export.txt` |

在词库管理界面按 `i` 导入、`e` 导出。

## 14. 蓝牙键盘与物理按键

### 14.1 蓝牙键盘

- **配对**：长按 `USER` 打开蓝牙管理，搜索到键盘后选择并长按连接；
- **自动重连**：开机或休眠唤醒后自动重连，60 秒内每 5 秒重试；期间按键盘任意键帮助唤醒；
- **管理**：蓝牙管理里双击添加/删除设备，长按连接，`Esc` 返回。

## 15. 文件管理、快捷编辑与 U 盘模式

### 15.1 本地文件管理器

- 设置 →「文件管理」：浏览 SD 卡；
- 快捷编辑/文件编辑模式下按 `Ctrl+E` 打开本地文件管理器：

| 按键 | 功能 |
|------|------|
| `a` | 新建文件 |
| `r` | 改名 |
| `d` | 删除（`Enter` 确认） |
| `Enter` | 打开文件 / 进入目录 |
| `Esc` | 关闭 |

### 15.2 Web 文件管理

设置 →「文件管理」，设备连上 WiFi 后屏幕上会显示
`http://<设备 IP>:<端口>`。在同一局域网的电脑浏览器里打开即可管理 SD 卡文件。
若设置了「文件管理密码」，请求需要携带令牌（页面会提示输入）。

### 15.3 U 盘模式

设置 →「文件管理」→「U 盘模式」：设备作为 U 盘挂载到电脑，可直接拖拽文件。

- 进入期间串口会断开，属正常现象；
- 退出前请先在电脑上**安全弹出**；
- 按 `Esc` 或长按 `BOOT` 退出，SD 卡会重新挂载。

### 15.4 快捷编辑与文件编辑

- **快捷编辑模式**：设置 →「模式设置」→ 工作模式切换为「快捷编辑」，重启生效。
  开机直接编辑 SD 卡根目录的 `0.txt`~`9.txt`，`Ctrl+0`~`Ctrl+9` 直接切换文件，
  `Ctrl+n`/`Ctrl+p` 上/下一个文件，`Esc` 保存并跳到设置。
- **文件编辑**：用文件管理器打开普通文本文件，默认自动保存并在重启后继续上次文件。

## 18. 休眠与电源

- **手动休眠**：长按 `BOOT`。休眠中按任意物理按键唤醒，唤醒后立即恢复休眠前的画面。
- **自动休眠**：设置 →「模式设置」→ 自动休眠，键盘/按键空闲 10 分钟后进入 light sleep。
- **休眠保留画面**：开启后休眠期间保留最后画面；关闭则白屏最省电。
- 状态栏显示电池电量；低电量时请及时充电。

## 19. 常见问题

**同步提示「写盘失败(SD内存不足)」**

- 确认 SD 卡已插好、格式为 FAT32；
- 重启设备后再试；
- 同步时避免同时进行蓝牙音频、语音识别等占用内部内存的操作。

**Flomo 同步失败 / 提示令牌过期**

- 检查设置里的 Flomo 邮箱和密码；
- 同步时程序会自动重新登录一次；
- 也可在设置里执行「生成 Flomo Token」后重试。

**同步拉到的条数和预期不符**

- Flomo 采用增量同步：只拉取上次游标之后有更新的笔记；
- 删除的笔记在远端是软删除，本地不会再出现在列表里；
- 若需要从头同步，可删除 `/sdcard/flomo/memos.json` 后重新同步（请先自行备份）。

**连不上 WiFi**

- 确认 SSID/密码正确，使用 2.4GHz 网络；
- 信号弱时靠近路由器重试；
- 检查设备是否已从休眠中唤醒。

**输入法不出候选**

- 按 `Ctrl+Space` 确认处于中文输入状态；
- 若是英文模式，候选为单词联想而非拼音候选。

**时间不对**

- 设置时区（如 `CST-8`）；
- 联网后执行「网络同步时间」；
- RTC 纽扣电池耗尽时需要重新校时。

**屏幕无响应**

- 长按 `BOOT` 进入休眠，再按任意物理按键唤醒；
- 仍无响应时断开电池/电源后重新开机。

**怎么升级固件**

- 浏览器打开 <https://autumnc.github.io/pjournal-esp32/>，用 Chrome/Edge 桌面版连接设备即可网页刷机；
- 命令行方式见仓库 `README.md` 的「编译」「烧录」章节。
