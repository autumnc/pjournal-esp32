使用帮助

    
  

  


    
一、这是什么

    

      正经人日记是跑在 ESP32-S3 上的个人日记固件（4.2″ RLCD 黑白全反射屏、蓝牙键盘输入）：
      自由写作与提示写作、拼音输入法、GTD 任务、大纲写作、灵感面板、AI 润色、语音听写、WebDAV / Flomo 同步、
      Web 文件管理。
      这个页面把它刷进设备 —— 不用装 ESP-IDF、esptool 或 Python，也不要用命令行。
    


    
二、浏览器要求

    
    
      
  • 需要 Chrome 或 Edge（桌面版）；Android Chrome 也可以。
    • 
      
  • Safari、Firefox、iOS 上任何浏览器都用不了 —— 它们没有 WebSerial 接口，这是浏览器层面的限制。
    • 
      
  • 页面必须是 https:// 或 localhost（本站在 GitHub Pages 上是 https，满足）。
    • 
      
  • 手机 / 平板需要一根 OTG 转接线才能接设备。
    • 
    


    
三、刷机步骤

    
    
      
  1. 用 Type-C 数据线把设备连到电脑。纯充电线不行 —— 线里没有数据线芯，电脑根本看不到设备。
    2. 
      
  2. 点「连接设备」，在弹出的串口列表里选
        USB JTAG/serial debug unit（就是设备本身；它内置 USB，不需要额外驱动）。
    3. 
      
  3. 连上后会显示芯片型号、flash 大小、MAC。确认是 ESP32-S3 再往下走。
    4. 
      
  4. 点「开始刷写」，等进度条走满（约 1 分钟；写入之后还会读回 flash 比对 MD5，
        这段进度条停在 100% 不动是正常的）。
    5. 
      
  5. 出现「✓ 刷写完成」后设备会自己重启进主界面，不用手动断电。
        若 5 秒内屏幕毫无反应，拔掉 USB 线再插上即可（固件已经写进去了）。
    6. 
    

    
刷写过程中不要拔线、不要关页面（页面会拦你一下）。中途断掉不会变砖 —— 再刷一遍就行。

    

      想刷别的版本（旧版本、自己编的、别人 fork 的）：在「固件」卡片里展开
      「或：用本地 / 其它版本的固件文件」，选一个整包
      pjournal-<版本>-merged.bin。页面会就地重跑同样的闸（长度 / 三处魔数 /
      你填的校验位），并且把算出来的 sha256、md5 显示出来给你核对。
      别选 pjournal-<版本>.bin —— 那是纯应用镜像，闸门会挡下它。
    


    
四、刷机不会丢什么

    
    
      
  • 这次写入的是 flash 里的固件区（引导程序 + 分区表 + 应用）。SD 卡完全不参与，
        所以卡上的东西一样不动：设置、日记正文、历史快照、GTD、大纲、灵感、词库导入导出、蓝牙配对信息。
        拔卡刷机也不影响。
    • 
      
  • WiFi 凭据、Flomo / WebDAV / Deepseek 的 Key 也都存在 SD 卡上，同样保留。
    • 
      
  • 刷完屏幕没变化是正常的 —— 设备本来就在跑同一个固件。
    • 
      
  • 真要「恢复出厂设置」，得另外抹掉 flash（不可撤销）：
        
    esptool.py --chip esp32s3 erase_flash
    
        抹完再插上 SD 卡，用本页面刷一遍固件。
    • 
    


    
五、刷完第一次开机

    
    
      
  1. 插一张 FAT32 microSD 卡（设备没有内置存储，日记和设置都在卡上）。
    2. 
      
  2. 开机后默认进个人日记模式：主界面按 f 自由写作、p 提示写作、
        v 翻过往日记、t GTD、o 大纲、s 设置。
    3. 
      
  3. 进 设置（主界面按 s）连 WiFi —— 联网后才能对时（RTC）和做 WebDAV / Flomo 同步。
    4. 
      
  4. 同一份设置里可以把「工作模式」切成快捷编辑：开机直接进编辑器编辑卡根目录的
        0.txt–9.txt（切换后需重启生效）。
    5. 
      
  5. 设置里还有 Web 文件管理：用浏览器打开设备地址就能管理 SD 卡文件
        （可设访问令牌）。
    6. 
    


    
六、物理按键

    
设备只有两个物理按键：BOOT（GPIO0）和用户按键（GPIO18）。日常操作靠蓝牙键盘。

    

      
按键单击双击长按

      

        用户按键
        蓝牙管理 / GTD 列表：↑
        蓝牙管理：添加（管理模式）或返回（扫描模式）；GTD 列表：切换平铺 / 项目树，项目列表进入选中项目
        蓝牙管理：连接选中设备；GTD 列表：切换标签；其它界面：进入蓝牙管理
      

      

        BOOT
        蓝牙管理 / GTD 列表：↓
        蓝牙管理：删除（管理模式）或返回（扫描模式）；GTD 项目树：返回项目选择菜单
        蓝牙管理：返回；其它界面：进入休眠
      

    

    

      在不是上面那些列表的界面里，双击还有两个直达动作：
      双击 BOOT = AI 全文润色，双击用户按键 = 语音听写。
    

    

      休眠：长按 BOOT 进入（之后单击不再休眠）；休眠期间按任意物理按键唤醒，唤醒后立刻回到休眠前那一屏。
      设置里开「自动休眠」后，键盘 / 按键空闲 10 分钟自己进 light sleep。
      「休眠保留画面」决定睡时留着最后画面还是白屏（更省电）。
    


    
七、蓝牙键盘

    
    
      
  • 配对入口：长按用户按键进蓝牙管理 → 双击添加 → 蓝牙键盘进入配对模式 → 长按用户按键连接选中设备。
    • 
      
  • 配对信息存在 SD 卡的 /sdcard/pjournal/bt_paired.dat，刷机不影响。
    • 
      
  • 开机和休眠唤醒后会自动重连：60 秒内每 5 秒重试一次，期间按一下键盘任意键（把它自己也唤醒）通常就接上了。
    • 
    


    
八、SD 卡目录

    
/sdcard/
├── 0.txt ~ 9.txt       # 快捷编辑文件（快捷编辑模式）
├── .quick_history/     # 快捷编辑历史快照（开启版本历史后生成）
├── pjournal/           # 日记
│   ├── entries/        # 日记文件 (YYYY-MM-DD_HHMMSS.txt)
│   ├── .history/       # 日记历史快照（每篇一个子目录，保留最近 10 个）
│   ├── settings.json   # 设置
│   └── bt_paired.dat   # 蓝牙配对信息
├── settings/           # 词库导入导出文件（userdict_* / userpredict_*）
├── gtd/                # GTD 任务管理
│   ├── gtd.json        # 任务数据
│   └── gtd_export_*.md # 任务导出
└── outline/            # 大纲写作 + 灵感面板
    ├── *.json          # 大纲项目
    └── inspiration.json  # 灵感数据

    
要备份，把整张卡拷走即可 —— 换机、重刷都不影响这些文件。


    
九、常见问题

    
点「连接设备」没反应 / 列表里没有设备

    
    
      
  • 确认用的是 Chrome 或 Edge（Safari / Firefox 没有 WebSerial，点了也不会有反应）。
    • 
      
  • 确认是数据线而不是纯充电线。
    • 
      
  • 关掉所有占用串口的程序：idf.py monitor、串口监视器、串口助手，
        以及本机的 cat /dev/ttyACM0。同一时刻只能有一个程序打开串口。
    • 
      
  • 列表里选的是 USB JTAG/serial debug unit；如果同时插了别的 USB 串口设备，注意别选错。
    • 
    

    
刷到一半失败 / 校验不通过

    
    
      
  • 不会有问题，重新刷一遍即可（固件是整包写入，没有"刷一半"的中间状态）。
    • 
      
  • 连续失败就换一根线、换一个 USB 口（尽量直插主板，别走 USB hub）。
    • 
    

    
刷完屏幕没变 / 设备不亮

    
    
      
  • 「屏幕没变」多半是正常的：设置、日记、SD 卡内容都不参与刷机，画面当然一样。
    • 
      
  • 刷完设备会重新枚举 USB，串口节点名会变（/dev/ttyACM0 可能变成
        /dev/ttyACM1），之前开着的 idf.py monitor 会失效，要重新开一个。
    • 
      
  • 真黑屏：按任意物理按键唤醒看看（可能只是睡过去了）；仍然不行就重刷一遍，或用
        erase_flash 抹掉后插卡重刷。
    • 
    

    
设备进入下载模式不自启

    
刷完应当自己重启。万一没有（页面会提示），拔掉 USB 线再插上即可 —— 固件已经写进去了。


    
十、不用网页、走命令行

    
装了 Python 的话，也可以直接从 Releases 下载整包手动刷：

    
pip install esptool

# 整包（引导程序 + 分区表 + 应用）→ 0x0
esptool.py --chip esp32s3 -b 460800 write_flash 0x0 pjournal-<版本>-merged.bin

# 或者只更新应用、不动引导程序 / 分区表 → 0x10000
esptool.py --chip esp32s3 -b 460800 write_flash 0x10000 pjournal-<版本>.bin

    
不要把 pjournal-<版本>.bin 刷到 0x0（它是纯应用镜像，
    刷错地址设备起不来）。本页面的固件闸口会挡掉这种误操作。

    
接串口看日志（空闲时固件不打日志，按一下按键才有输出）：

    
cat /dev/ttyACM0

    
烧完之后想开着串口观察，用 idf.py monitor 更好 —— 它会一直挂着，cat 会立刻 EOF。


    
十一、硬件与说明

    

      
主控ESP32-S3（双核 240MHz，16MB flash，8MB+ PSRAM）

      
屏幕4.2″ RLCD 黑白全反射屏 400 × 300，ST7305 驱动（SPI）

      
RTCPCF85063（I2C），带 CR2032 备份电池

      
键盘蓝牙 HID（BLE）

      
按键BOOT（GPIO0）+ 用户按键（GPIO18）

      
电池单节锂电池 3.7V，ADC 分压检测

      
存储microSD，SDMMC 1-line，FAT32

    

    

      刷机有风险（但随时可以用同一个页面重刷）。本页面的固件与工具全部同源托管，
      刷前会校验长度、三处镜像魔数和 sha256 / md5。
