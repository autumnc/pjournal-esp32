# pjournal-esp32

ESP32-S3 上的个人日记工具，配备 4.2 寸 RLCD 黑白全反射屏，支持蓝牙键盘输入、拼音输入法、GTD 任务管理、大纲写作、多端同步等功能。

## 硬件需求

| 组件 | 规格 |
|------|------|
| **主控** | ESP32-S3 (PSRAM 8MB+, Flash 16MB) |
| **屏幕** | RLCD 4.2" 400×300，ST7305 驱动 (SPI) |
| **RTC** | PCF85063 (I2C)，带 CR2032 电池 |
| **SD卡** | SDMMC 1-line 模式，FAT32 格式 |
| **键盘** | 蓝牙 HID 键盘 (BLE) |
| **电池** | 单节锂电池 (3.7V)，ADC 分压检测 |
| **按键** | BOOT (GPIO0) + 用户按键 (GPIO18) |

**引脚定义**: 见 `main/user_config.h`

## 功能特性

- **自由写作** / **提示写作**：新建日记条目
- **拼音输入法**：中文输入、词库联想、用户词典（单字优先），`Ctrl+Space` 中/英切换，`Shift+Space` 全角/半角，`Ctrl+Shift+F` 繁/简切换，左Shift单击临时英文模式
- **GTD 任务管理** (`t`)：分层任务、项目、标签/情境、筛选、归档、任务摘要
- **大纲写作** (`o`)：大纲式写作，支持项目、标签、标题层级、详情面板、摘要
- **灵感面板** (`Ctrl+I`)：快速记录灵感，支持关键词、内容检索、复制到剪贴板
- **蓝牙键盘**：一键配对 / 自动重连（10 秒间隔）
- **过往日记浏览**：按日期排序、查看详情、编辑
- **编辑器**：Markdown 实时渲染、自动保存、选择/复制/粘贴、发送至 Flomo
- **快捷编辑**：SD 卡根目录 0-9.txt 十个文件快速编辑，自动保存、重启续编上次文件，`Ctrl+0-9`/`Ctrl+n`/`Ctrl+p` 切换文件
- **发送至 Flomo**：`Ctrl+F` 即时反馈面板，防止重复发送
- **WebDAV 同步**：上传/下载日记到远程存储，同步状态即时显示
- **AI 提示生成**：`Ctrl+P` 根据个人设置生成写作提示
- **NTP 时间同步**：支持自定义 NTP 服务器
- **Web 文件管理**：通过浏览器管理 SD 卡文件

## Markdown 渲染

编辑器支持 Markdown 实时语法渲染（可在「设置」中关闭 Markdown渲染）。所有标记均替换为同宽内容，光标、选中、折行保持对齐。

### 块级标记

| 输入 | 渲染效果 |
|------|----------|
| `#` ~ `######` 标题 | 行首标记替换为标题符号，内容加粗 + 下划线 |
| `- ` / `* ` / `+ ` 无序列表 | `• ` 圆点 |
| `1. ` / `1)` / `1、` 有序列表 | 序号加粗，整体右移 1 格 |
| `一、` / `二、` / `十、` 中文序号 | 中文序号加顿号加粗，整体右移 1 格 |
| `- [ ]` / `- [x]` 任务 | `☐` / `✓` |
| `> ` 引用 | 左侧竖线 + 内容缩进 |
| `---` / `***` / `___`（≥3 个） | 水平分割线 |
| ```` ``` ```` 代码围栏 | 围栏行画横线，围栏内内容反白 |

### 行内标记

| 输入 | 渲染效果 |
|------|----------|
| `**加粗**` / `***加粗+下划线***` | 加粗 / 加粗 + 下划线 |
| `*斜体*` | 下划线 |
| `` `代码` `` | 反白 |
| `[链接](https://…)` | 反白 + 下划线 |
| `~~删除~~` | 删除线 |
| `==高亮==` | 着重号 |
| `\*` | 转义，显示原文 |

列表行在行尾回车自动续行：下一行带同款标记；有序列表序号自动递增（`1.`→`2.`、`一、`→`二、`）。空列表项回车结束列表。

### 物理按键

| 按键 | 单击 | 双击 | 长按 |
|------|------|------|------|
| **用户按键 (GPIO18)** | 蓝牙管理/GTD列表: `↑` | 蓝牙管理: 添加(管理模式)/返回(扫描模式); GTD列表: 平铺/项目树切换任务状态, 项目列表进入选中项目 | 蓝牙管理: 连接选中设备; GTD列表: 切换标签; 其他: 进入蓝牙管理 |
| **BOOT (GPIO0)** | 蓝牙管理/GTD列表: `↓` | 蓝牙管理: 删除(管理模式)/返回(扫描模式); GTD项目树: 返回项目选择菜单 | 蓝牙管理: 返回; 其他: 进入休眠(任意按键唤醒) |

> 休眠:长按 BOOT 进入(单击不再休眠),休眠中按任意物理按键唤醒。

## 编译

### 环境要求

- ESP-IDF **5.5**
- Python 3.14+
- 目标芯片: ESP32-S3

### 编译步骤

```bash
# 加载 ESP-IDF 环境
. /path/to/esp-idf/export.sh

# 编译
idf.py build

# 生成合并固件（bootloader + partition + app）
esptool.py --chip esp32s3 merge_bin -o build/pjournal-merged.bin \
  --flash_mode dio --flash_size 16MB --flash_freq 80m \
  0x0 build/bootloader/bootloader.bin \
  0x8000 build/partition_table/partition-table.bin \
  0x10000 build/pjournal.bin
```

### 烧录

```bash
# 合并固件一步烧录
esptool.py --chip esp32s3 -p /dev/ttyUSB0 -b 460800 \
  --before default_reset --after hard_reset \
  write_flash 0x0 build/pjournal-merged.bin

# 或分步烧录
idf.py -p /dev/ttyUSB0 flash
```

## SD 卡目录结构

```
/sdcard/
├── 0.txt ~ 9.txt       # 快捷编辑文件（快捷编辑模式）
├── pjournal/          # 日记
│   ├── entries/       # 日记文件 (YYYY-MM-DD_HHMMSS.txt)
│   ├── settings.json  # 设置
│   └── bt_paired.dat  # 蓝牙配对信息
├── gtd/               # GTD 任务管理
│   ├── gtd.json       # 任务数据
│   └── gtd_export_*.md  # 任务导出
└── outline/           # 大纲写作 + 灵感面板
    ├── *.json         # 大纲项目
    └── inspiration.json  # 灵感数据
```

## 设置项

| 设置 | 说明 |
|------|------|
| 工作模式 | 个人日记 / 快捷编辑（切换重启生效） |
| Deepseek Key | AI 提示生成 API Key |
| Flomo 邮箱/密码 | Flomo API 登录凭证 |
| 生成 Flomo Token | 由邮箱/密码生成 API Token |
| WebDAV URL/用户/密码 | 远程同步地址 |
| 个人经历/爱好 | AI 提示上下文 |
| WiFi SSID/密码 | 网络连接 |
| 时区 | 如 `CST-8` |
| NTP 服务器 | 如 `pool.ntp.org` |
| 自动保存 | 开启后 3 秒无操作自动存储 |
| 自动休眠 | 开启后键盘/按键空闲 10 分钟进入 light sleep 休眠，物理按键唤醒 |
| 休眠保留画面 | 开启后休眠期间保留最后画面；关闭则白屏最省电 |
| 字体大小 | 候选字与正文显示字号 |
| 网络同步时间 | 联网后同步 RTC 时间 |
